Module 05 — Cross-Validation · Ridge · Grid Search

✓ Completed

Detect overfitting with k-fold cross-validation, stabilise high-degree polynomials with Ridge, and tune hyper-parameters via GridSearchCV. Auto dataset: 4-fold CV mean R² 0.522 (±0.291); degree-5 polynomial overfits hard (train R² 0.557 vs test R² −29.87); Ridge tuned validation R² 0.564 (train 0.859); GridSearchCV picks α = 10000. Laptops dataset: single-feature CPU_frequency CV R² 0.127; 1–5 order polynomial test R² drops 0.053 → −1.376; Ridge validation R² 0.423; GridSearchCV best α = 10.

Notebooks: Module05_Lab01_CrossValidation_Ridge_Auto.ipynb · Module05_Lab02_CrossValidation_Ridge_Laptops.ipynb

Data: module_5_auto.csv · laptops.csv (polynomial features)

Module 06 — House Pricing & Insurance Cost

✓ Completed

Final project and practice: predict King County house prices and medical insurance charges. House pricing: sqft_living linear regression R² 0.493 → multiple features R² 0.658 → full pipeline R² 0.751; Ridge (α=0.1) R² 0.6479; 2nd-order polynomial + Ridge R² 0.700. Insurance cost: smoker-only R² 0.622 → all features R² 0.750 → pipeline R² 0.845; Ridge (α=0.1) test R² 0.676; 2nd-order polynomial Ridge test R² 0.784.

Notebooks: Module06_FinalProject_HousePricing.ipynb · Module06_PracticeProject_InsuranceCost.ipynb

Data: kc_house_data_NaN.csv · medical_insurance_dataset.csv (Kaggle King County House & Medical Insurance)
